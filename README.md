# Мёд.kz

Сайт по продаже мёда в Астане с доставкой по всему Казахстану. Чистый HTML, CSS и JavaScript без сборки.

## Как открыть

Откройте `index.html` двойным щелчком или запустите `python3 -m http.server 8000` и перейдите на `http://localhost:8000`.

## Структура

- `index.html`, `styles.css` — страница и оформление.
- `js/jar3d.js` — 3D-банка (общая для сцены и облаков точек).
- `js/scene.js` — главный экран: 3D-сцена, свет под курсором, выбор банки.
- `data/honey.js` — **список мёда: единственный файл, который нужно править, чтобы добавить сорт**.
- `js/products.js` — строит карточки, подбирает цвета и рисует картинки-заглушки из `data/honey.js`.
- `js/honey-pot.js` — горшок с мёдом в правом нижнем углу: крышка открывается по мере прокрутки. Размер и отступ — `--pot-size` и `--pot-gap` в `styles.css`.
- `js/main.js` — загрузчик, шапка, выезжающая стопка продуктов (блоки «досаживаются» в окно), история, форма.
- `assets/story` — иллюстрации для хронологии (SVG). Картинки мёда сайт рисует сам; свои фото указываются в `фото` в `data/honey.js`.
- `fonts/` — Cormorant Garamond (заголовки, цены, меню), Onest (текст, подписи). Лицензии OFL лежат рядом.
- `vendor/` — three.js r149 (MIT), GSAP 3.12 с ScrollTrigger и ScrollToPlugin.
- `design/` — манифест оформления и плакат из прошлой итерации.

## Как добавить мёд

1. Откройте `data/honey.js`.
2. Скопируйте любой блок `{ ... }` в списке `HONEY_PRODUCTS`, вставьте в конец и поменяйте значения в кавычках.
3. Сохраните файл и обновите страницу: карточка, банка на главном экране и плашка после клика по ней появятся сами.

Обязательны только `название` и `цвет` (цвет мёда, например `'#9a5a14'`): цвета фона и акцента подберутся сами, а пока нет фото, банку нарисует сайт. Текст на банке по умолчанию совпадает с названием; его можно изменить полями `надпись_на_банке` и `надпись_мелко`, а цвета этикетки — `цвет_этикетки` и `цвет_надписи`. Остальные поля (`слоган`, `описание`, `сезон`, `плюсы`, `цена`, `старая_цена`, `фото` и другие) необязательны. Чтобы спрятать сорт, не удаляя его, напишите `показывать: false`. Номер WhatsApp для кнопки «Купить» указывается в `HONEY_SETTINGS`.

## Что нужно заменить

Цены, сроки сбора, названия сортов (в `data/honey.js`), история по годам, телефон `+7 700 000 00 00`, почта `info@med.kz` и Instagram `@med.kz` — заглушки.
Форма контактов открывает письмо в почтовой программе на `info@med.kz`; своего сервера у сайта нет.
